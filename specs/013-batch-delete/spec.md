# 013 批量删除

## 目标

在衣橱列表里一次选中多件衣服，确认后一起删除。

## 不做什么

- 不改详情页里单件删除的句子和按钮。
- 不删除布料、成员。
- 不调用识别，不重做抠图。

## 流程

1. 衣橱有衣服时，标题旁有「选择」。点开之后，再点卡片是选中或取消，不会进入详情。
2. 可以点「全选」，把当前列表里的衣服都选上。再点一次取消这些选择。
3. 选中至少一件时，出现「删除」。确认框写「删除这 N 件衣服」。确认后这些衣服从列表消失，搭配里对应的槽位也去掉。
4. 点「完成」退出选择。没进入选择时，点卡片仍进入详情。

## 页面

「录入衣服」仍是这一页的主按钮。「选择」「全选」「完成」是线框按钮。「删除」用红色。选中的卡片有一圈系统蓝。

## 数据与接口

沿用 `DELETE /api/garments/{id}`。删除时同时去掉搭配表里引用这件衣服的槽位。

## 验收

1. 不点「选择」时，点卡片仍进入详情。
2. 选中两件并确认删除后，这两件从衣橱消失，其余衣服还在。
3. 点取消后，衣服仍在。
