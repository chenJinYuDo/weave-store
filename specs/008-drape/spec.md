# 008 垂坠

## 目标

衣服放进搭配后，家里电脑按纤维和版型做一次小规模 XPBD，把结果缓存下来。电脑和手机旋转查看的都是减面后的显示网格。棉麻看起来比针织挺，针织比雪纺挺。印花贴在模板上。复杂门襟、帽子和荷叶边用最接近的模板，不追求制版软件的精度。

## 不做什么

- 不生成 SMPL-X 人体。模型文件仍不下载。视口继续说明还不能生成人体。
- 不把生活照、衣服或布料发给 DeepSeek，也不做抠图。
- 不把计算网格发给浏览器。手机不能拖衣服，也不能改叠穿。
- 鞋和配饰不垂坠。布料仍不能拖进搭配台。
- 网格只有几千个顶点，这一份用 NumPy 在 CPU 上算完，不安装 Taichi，也不使用 NVIDIA。
- 不新增衣服、布料或成员的字段。

## 流程

1. 宽屏把衣服拖进视口，或从叠穿取下。槽位先按原来的规则保存。
2. 需要垂坠的衣服在家里电脑上求解。视口在算出结果前显示「正在垂坠」。
3. 求解按模板铺一层布片，顶部固定，再用拉伸、弯曲和躯干碰撞迭代。纤维决定刚度：雪纺、真丝、丝绸最软；名称或纤维里有针织的用针织；棉、麻、牛仔，以及外套和牛仔裤更挺；其余按普通梭织。
4. 计算网格留在 `data/drapes/`。显示网格隔点取样，每件不超过一万个三角面。有抠图时，贴图长边缩到 1024 以内，贴在模板的 UV 上。
5. 同一件衣服、同一个模板、同一种软硬、同一张抠图再次搭配时，直接用缓存。
6. 窄屏只打开「未选择」这一套已经算好的显示网格，可以旋转。还没有结果时，仍只显示「请在电脑上搭配」。

## 页面

宽屏仍是衣橱、视口、叠穿三列。拖入、取下、成员选择和槽位规则不变。

视口在有衣服垂好之后，正文仍是「还不能生成人体」，下面是可旋转的显示网格，不再铺平面抠图。方向键可以左右转动。没有叠穿时，不显示网格。鞋和配饰只留在叠穿里，视口说明「这几件不需要垂坠」。求解失败时说明「垂坠没有完成」，并仍显示平面卡片。

窄屏有显示网格时，标题下是同一块可旋转的网格，没有衣橱列、叠穿列和「取下」。没有显示网格时，仍是「请在电脑上搭配」。

## 数据与接口

搭配表不变。垂坠文件在 `data/drapes/`，不进 git。

八类模板：T 恤、衬衫、针织、外套、西裤、牛仔裤、半裙、连衣裙。对应关系：

- 上衣，名称或纤维含「针织」：针织。名称含「T恤」：T 恤。其余上衣：衬衫。
- 外套：外套。下装含「牛仔」：牛仔裤。其余下装：西裤。
- 半裙：半裙。连衣裙：连衣裙。
- 鞋、配饰：不求解。

`GET /api/outfits` 和 `PUT /api/outfits` 在原有字段外增加 `display_url` 和 `message`。有显示网格时 `display_url` 指向 `GET /api/outfits/display.gltf`，并带版本参数。没有结果时 `display_url` 为空。

`GET /api/outfits/display.gltf?member_id=` 只返回这一套的显示 glTF。成员规则与搭配接口相同。还没有结果时 404，说明「还没有垂坠结果」。

## 验收

1. 宽屏把白衬衫拖进视口。视口仍写「还不能生成人体」，并出现可以旋转的衣服网格。方向键能改变视角。刷新后网格还在。
2. 取下白衬衫后，网格消失，叠穿回到「还没有叠穿」。再拖回去后，网格重新出现。
3. 窄屏在这套结果已经存在时能看到网格，看不到「取下」。把结果取掉之后，窄屏回到「请在电脑上搭配」。
4. 显示网格的三角面少于计算网格，并且不超过一万。浏览器拿到的是显示 glTF，计算文件没有下载地址。
5. 同一件衬衫模板上，雪纺的下摆低于针织，针织低于棉麻。
6. 有抠图时贴图长边不超过 1024。
7. 布料页没有拖拽入口。白衬衫和亚麻布仍在。接口日志里没有 DeepSeek。
