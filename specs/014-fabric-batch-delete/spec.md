# 014 布料批量删除

## 目标

在布料列表里一次选中多块布，确认后一起删除。

## 不做什么

- 不改详情页里单块删除的句子和按钮。
- 不删除衣服、成员。
- 不调用识别，不重做抠图。

## 流程

1. 布料库有布时，标题旁有「选择」。点开之后，再点卡片是选中或取消，不会进入详情。
2. 可以点「全选」，把当前列表里的布都选上。再点一次取消这些选择。
3. 选中至少一块时，出现「删除」。确认框写「删除这 N 块布料」。确认后这些布从列表消失。
4. 点「完成」退出选择。没进入选择时，点卡片仍进入详情。

## 页面

「录入布料」仍是这一页的主按钮。「选择」「全选」「完成」是线框按钮。「删除」用红色。选中的卡片有一圈系统蓝。

## 数据与接口

沿用 `DELETE /api/fabrics/{id}`。

## 验收

1. 不点「选择」时，点卡片仍进入详情。
2. 选中两块并确认删除后，这两块从布料库消失，其余布料还在。
3. 点取消后，布料仍在。
