# 015 手机搭配

## 目标

窄屏打开搭配，可以选成员、把衣服拖进视口、推荐一套、取下。叠图和槽位规则与宽屏相同。

## 不做什么

- 不恢复人体，也不显示垂坠网格。
- 不把布料拖进搭配台。
- 不改宽屏的三列：衣橱、视口、叠穿。
- 不改衣服、布料详情里的删除。
- 不删除已有的「白衬衫」和「亚麻布」。

## 流程

1. 窄屏底栏有四项：衣橱、布料、搭配、成员。点「搭配」进入搭配页。
2. 成员默认「未选择」。视口是一张 3:4 的平面叠图。没有衣服时，图里写「把衣服拖到这里」。
3. 从衣橱把衣服拖到视口上。拖入套装时，清掉上衣、外套、下装、半裙、连衣裙。拖入连衣裙时，清掉上衣、下装、半裙、套装。拖入上衣、下装或半裙时，清掉套装和连衣裙。拖入外套时，清掉套装。松手后保存，刷新后仍在。
4. 点「推荐一套」。能凑出来时，视口换成这一套并保存。凑不出来时写「还不能凑成一套」，原来的叠穿不动。
5. 叠穿里点「取下」，这一槽从叠图消失并保存。

## 页面

窄屏标题「搭配」。标题下是成员和「推荐一套」，然后是叠图，再是衣橱，最后是叠穿。「推荐一套」是线框按钮。拖到视口上时，视口用系统蓝的淡底标出。

底栏贴底，四项均分。当前项是系统蓝。

宽屏布局、按钮和文案保持原样。

## 数据与接口

不新增接口。沿用 `GET /api/outfits`、`PUT /api/outfits` 和 `GET /api/outfits/suggest`。

## 验收

1. 窄屏底栏能看到「搭配」。打开后能看到叠图和衣橱，页面上没有「请在电脑上搭配」。
2. 把一件衣服拖进视口后，叠图里能看到它，刷新后仍在。点「取下」后，它从叠图消失。
3. 窄屏点「推荐一套」。能凑出来时视口换成结果；凑不出来时写「还不能凑成一套」，原来的叠穿不动。
4. 宽屏仍是三列。衣橱里的「白衬衫」和布料库里的「亚麻布」都还在。
